ABOUT

Hi! I'm a Software Engineer who loves building both digital applications and embedded systems. I thrive at the intersection of software and hardware, where web interfaces meet real-world devices.

I have hands-on experience developing:
Responsive websites and web applications using PHP, JavaScript, HTML/CSS, and Tailwind.
Database-driven systems with MySQL for storing and retrieving user or system data
Firmware for microcontrollers (ESP32, STM32, AVR) written in C/C++
IoT-based solutions involving Bluetooth and Wi-Fi for wireless data transmission

My projects often bridge the gap between software and embedded systems—creating CNC control panels, integrating touchscreen displays with custom firmware, or enabling Bluetooth control of hardware devices.
